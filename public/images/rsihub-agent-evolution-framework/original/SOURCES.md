# 原始图表与来源说明

本目录保存 `simple-agent-lab/RSIHub`（commit `d655429`）与论文 *RSIHub: A Composable Framework for Agent-Evolution Methods*（`arXiv:2610.32253v1`）的原始配图及等比渲染图：

- `RSIHub-agent-workflow.png`：论文 Figure 1，展示 Recipe-Driven 与 Agent-Driven 两种运行模式、七阶段演化循环与受保护运行时边界。来源：`https://arxiv.org/html/2610.32253v1/RSIHub-agent-workflow.png`。
- `viewer.jpeg`：论文 Figure 2，展示 `evolve view` 只读实验查看器在 `tau3-banking-gepa-miniswe` 实验上的界面截图（Generation 8 Champion、代际树与文件 diff）。来源：`https://arxiv.org/html/2610.32253v1/arxiv/figures/viewer.jpeg`。
- `architecture.svg` / `architecture.png`：仓库 `docs/assets/architecture.svg` 原图及等比 PNG 渲染。
- `benchmark-results-rsihub-v2.svg` / `benchmark-results-rsihub-v2.png`：仓库 `docs/assets/benchmark-results-rsihub-v2.svg` 原图及等比 PNG 渲染，展示 Terminal-Bench 2 与 $\tau^3$ Banking 上四种演化策略与两类种子 Agent 的对比结果。
- `paper-poster-lora-gen0.png` 与 `paper-poster-lora-gen2.png`：仓库 `docs/assets/` 中的 Paper2Poster Skill 演化对比案例原图（Gen 0 12 行最小 Skill vs. Gen 2 演化后 Skill）。

许可证说明：仓库采用 Apache-2.0 许可证，论文发布于 arXiv（`arXiv:2610.32253`）。
